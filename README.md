# Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript. This site introduces who I am, highlights my background, and links to the projects I have built during my time studying Business Analytics and Information Systems at the University of South Florida.

**Live Site:** [asce260901.github.io/portfolio/](https://asce260901.github.io/portfolio/)

## About

This portfolio was built to present my skills and projects in a clean, professional format suitable for sharing with employers and internship recruiters. It includes sections for my background, technical skills, and featured work.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (deployment)

## How to Run

The site is deployed live at the link above. To run it locally:

1. Clone the repository:
```bash
git clone https://github.com/Asce260901/portfolio.git
```
2. Open `index.html` in your browser.

## What I Learned

Building this portfolio taught me how to structure a professional web presence, apply responsive design principles, and deploy a static site using GitHub Pages. I also practiced writing clean, semantic HTML and organizing CSS for maintainability.
